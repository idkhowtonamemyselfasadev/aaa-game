# AAA game (long-running autonomous build)

An open-world action-adventure between *Tears of the Kingdom* and *Black Myth: Wukong*,
built one Claude Code session per night in Godot 4. The brief is `CLAUDE.md`, the state is
`PROGRESS.md`, the design is `DESIGN.md` once milestone 0 is done.

Run a session by hand: `tools/session.sh`. Screenshots: `tools/shots.sh`.
